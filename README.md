# BOOST ME + IA
La foto y el texto se envían a `/api/analyze-meal`. La API key nunca va en el HTML.

## Deploy
1. Subí esta carpeta a GitHub.
2. Importá el repo en Vercel.
3. En Vercel agregá la variable de entorno `OPENAI_API_KEY`.
4. Deploy.
5. Abrí la URL de Vercel y probá Comidas > Registrar comida.
